### Como eu trabalho

**Produto inteiro, não só código.**
Venho do design e do UX. Decido interface e implementação juntas, do briefing ao deploy.

**Plataforma nativa antes de dependência.**
HTML, CSS e recursos do navegador primeiro. Menos peças significam menos falhas, menos peso e mais segurança.

**A ferramenta certa para o contexto.**
Não tenho ferramenta favorita, tenho critério: já escolhi page builders por produtividade e por estabilidade, e já propus mudanças de infraestrutura.

**Web legível para pessoas e para máquinas.**
Conteúdo estruturado, rápido e acessível é melhor para quem usa o site e para quem o indexa, incluindo buscadores e IA.
